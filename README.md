# 🐋 Docker To-Do List

## ✨ Descrição Breve  
Este projeto consistiu em **conteinerizar** uma aplicação de lista de tarefas (To-Do List) e criar a **conexão entre as aplicações**. A aplicação já estava desenvolvida, mas foi necessário criar **Dockerfiles** para configurar o ambiente de **front-end**, **back-end** e **testes**, além de aprender comandos básicos do Docker. **OBSERVAÇÃO IMPORTANTE** os **arquivos desenvolvidos por mim** estão localizados dentro da pasta **docker-commands**.

## 🚀 Como Rodar o Projeto  
1. Clone o repositório:  
   ```bash
   git clone https://github.com/Gzuuu/docker-todo-list.git
   ```  
2. Acesse a pasta do projeto:  
   ```bash
   cd docker-todo-list
   ```  
3. Instale as dependências do projeto:  
   ```bash
   npm install
   ```  
4. Caso queira rodar os testes localmente:  
   ```bash
   npm test
   ```  

## 🛠️ Tecnologias Utilizadas  
- **Docker**  
- **Node.js**  
- **NPM**  

## 📚 Principais Aprendizados  
- Primeiros passos com **Docker** e criação de **Dockerfiles**.  
- Entendimento de como **conteinerizar** aplicações para facilitar o desenvolvimento e a implantação.  
- Como conectar **diferentes partes** de uma aplicação (front-end, back-end e testes) usando containers.
